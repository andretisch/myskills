# Шаблон сопроводительного — DevOps

## Структура

1. **Приветствие** — 1 предложение, без «15 лет и руковожу отделом».
2. **Match по стеку** — 4–6 буллетов под JD (GitLab CI, Proxmox, Nginx, …).
3. **Ответ на технический вопрос** (если есть в вакансии) — 30–40% объёма.
4. **Почему я + контакты** — 2–3 предложения, ссылка на GitHub.

## Чего избегать

- «15 лет в ИТ, руковожу отделом, внедряю AI» — для DevOps отвлекает.
- Только теоретический ответ на вопрос без match по остальному JD.
- Второй вариант K8s, если вакансия явно про VM + PHP + Proxmox (можно одной строкой «альтернатива — …»).
