# Пакет резюме: DevOps / Platform Engineer

Рабочая папка для отдельного трека **DevOps** — не смешивать с резюме AI/ML и «Главный сисадмин / IT lead».

## Файлы

| Файл | Назначение |
|------|------------|
| [resume.md](resume.md) | Черновик резюме под DevOps (источник для hh.ru / PDF) |
| [gaps-and-growth-plan.md](gaps-and-growth-plan.md) | Слабые места, пробелы по вакансиям, план прокачки |
| [cover-letter-template.md](cover-letter-template.md) | Шаблон сопроводительного письма |
| [rejections/](rejections/) | Разборы отказов по вакансиям |

## Как пользоваться

1. Перед откликом — сверить JD с `gaps-and-growth-plan.md` (что закрыто, что дописать в письмо).
2. Обновить `resume.md` под конкретную вакансию (ключевые слова из JD).
3. Скопировать резюме на hh.ru или собрать PDF.
4. После отказа — добавить кейс в `rejections/` и обновить план прокачки.

## Принципы позиционирования

- **Hands-on инженер**, не «руководитель отдела» в первом абзаце.
- Опыт DevOps/SRE считать от **реальных задач** (инфра, CI/CD, мониторинг), а не от должности.
- AI/ML — убрать из DevOps-откликов (отдельный трек).
- Каждый навык в резюме — с **примером** (что делал, какой стек, какой результат).
